Course Description:
This course provides an introduction to computer science fundamentals, including programming, algorithms, data structures, and computational thinking. Students will learn to write programs in Python and develop problem-solving skills.

Learning Objectives:
- Understand fundamental programming concepts
- Develop algorithmic thinking skills
- Learn basic data structures (arrays, lists, trees)
- Understand computational complexity
- Apply problem-solving techniques to real-world problems

Course Topics by Week:
Week 1-2: Introduction to Python, Variables, Data Types
Week 3-4: Control Flow (if/else, loops)
Week 5-6: Functions and Modules
Week 7-8: Data Structures (Lists, Dictionaries, Sets)
Week 9: Midterm Review and Exam
Week 10-11: Object-Oriented Programming
Week 12-13: Algorithms and Complexity
Week 14: File I/O and Error Handling
Week 15: Final Project Presentations
