# Sample Course Materials

This folder contains sample course materials that you can use to test the Canvas Course Chatbot.

## Files Included

- `sample-syllabus.txt` - A complete course syllabus with all the information students typically need

## How to Use

1. Start the application (frontend and backend)
2. Navigate to the Instructor Portal
3. Enter a course name (e.g., "Introduction to Computer Science")
4. Upload the `sample-syllabus.txt` file
5. Click "Process with Claude AI"
6. Once processed, go to the Student Chat and ask questions like:
   - "What are the assignment deadlines?"
   - "What is the grading policy?"
   - "When are office hours?"
   - "What topics will be covered?"

## Creating Your Own Test Files

You can create additional test files in TXT, PDF, DOCX, or HTML format. The chatbot works best with:
- Course syllabi
- Assignment descriptions
- Course policies
- Lecture notes
- Reading materials

Just make sure files are under 10MB each.
